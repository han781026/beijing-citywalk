💾 备份与迁移

所有记录只保存在这台设备的这个浏览器里，清除浏览器数据会导致丢失。建议每隔一两个月导出一次备份文件，发到微信「文件传输助手」长期保存；换设备时用「恢复备份」导入即可。

📱 怎么当成 App 用

1️⃣ 网址：han781026.github.io/beijing-citywalk，发到微信「文件传输助手」，手机点开最方便。
2️⃣ iPhone：在微信里打开链接后点右上角「…」→「在 Safari 中打开」→ 分享 →「添加到主屏幕」；安卓：用 Chrome 等浏览器打开后菜单里选「添加到主屏幕」。
3️⃣ 以后从桌面图标进入，就是全屏小程序体验。
⚠️ 注意：微信内置浏览器里添加的记录可能被清掉，请养成从 Safari / 桌面图标进入的习惯。
🔄 想更新应用？把新的 index.html 重新上传到 GitHub 仓库（Add file → Upload files，同名自动覆盖）即可。
